# 🎲 Ludo Cash — চালু করার নির্দেশিকা

## ফোল্ডারে কী আছে
```
server.js        ← সার্ভার (ডাটাবেস, ওয়ালেট, ম্যাচ, অ্যাডমিন API)
admin.html       ← অ্যাডমিন প্যানেল (সার্ভার পাসওয়ার্ড দিয়ে খোলে, public-এ রাখবেন না)
package.json, package-lock.json, .node-version   ← সার্ভার নিজে এগুলো দেখে সব প্যাকেজ বসায়
public/          ← ওয়েবসাইট (লবি, গেম, আইকন, অ্যাপ ইনস্টলের ফাইল)
_tests/          ← পরীক্ষা (সার্ভারে না দিলেও চলে)
CHECKUP.md       ← কী কী পরীক্ষা হয়েছে, কী ঠিক করা হয়েছে, কোন ঝুঁকি বাকি — প্রকাশের আগে অবশ্যই পড়ুন
```
⚠️ এই জিপে `ludo.db` (টাকার হিসাব), `.jwt_secret` ও `node_modules` ইচ্ছে করেই **নেই**। সার্ভার প্রথমবার চালু হলে নিজেই নতুন খালি ডাটাবেস বানাবে।

## পিসিতে চালিয়ে দেখা (প্রথমে এটা করুন)
Node.js **২২ বা তার বেশি** লাগবে (nodejs.org থেকে LTS নামান)।
```
npm ci
set ADMIN_PASS=আপনার-শক্ত-পাসওয়ার্ড        (Linux/Mac: export ADMIN_PASS=...)
npm start
```
ব্রাউজারে `http://localhost:3000` — অ্যাডমিন: `http://localhost:3000/admin` (ইউজার `admin`)

## Environment variables (হোস্টিংয়ের Environment/Variables ঘরে বসাবেন)
| নাম | দরকার? | কাজ |
|---|---|---|
| `ADMIN_PASS` | **অবশ্যই** | অ্যাডমিন পাসওয়ার্ড (১০+ অক্ষর, শক্ত)। না দিলে প্রতিবার নতুন অস্থায়ী পাসওয়ার্ড হয় |
| `DATA_DIR` | **অবশ্যই** | ডাটাবেস যে **স্থায়ী ডিস্কে** থাকবে (যেমন `/var/data`) |
| `JWT_SECRET` | ভালো | লম্বা র‍্যান্ডম লেখা (৪০+ অক্ষর)। না দিলে `DATA_DIR`-এ ফাইলে সেভ হয় |
| `BKASH_NUMBER` / `NAGAD_NUMBER` | ভালো | ইউজাররা যে নাম্বারে টাকা পাঠাবে। না দিলে `01818714458` দেখাবে — **ঠিক আছে কিনা মিলিয়ে নিন** |
| `FEE_PCT` | ঐচ্ছিক | প্ল্যাটফর্ম ফি % (এখন ডিফল্ট ৫)। ১০% চাইলে `10` দিন |
| `PORT` | না | হোস্ট নিজেই দেয় |

## অনলাইনে দেওয়ার ধাপ (যেকোনো হোস্টে একই)
1. কোডটা GitHub-এ **Private** রিপোজিটরিতে তুলুন (`.gitignore` আগে থেকেই ডাটাবেস/সিক্রেট আটকায়)।
2. এমন হোস্ট নিন যেখানে **স্থায়ী ডিস্ক (persistent disk/volume)** পাওয়া যায় এবং সার্ভার ২৪ ঘণ্টা চালু থাকে (Render-এর Free প্ল্যান/Vercel/Netlify চলবে না — ডাটা মুছে যায় বা ঘুমিয়ে পড়ে)। দাম ও সুবিধা হোস্টের সাইটে মিলিয়ে নিন; একটা সস্তা VPS-ও চলবে।
3. Build command: `npm ci` — Start command: `npm start`
4. ডিস্ক বানিয়ে (যেমন `/var/data`) `DATA_DIR=/var/data` দিন, সাথে `ADMIN_PASS` ইত্যাদি।
5. **শুধু একটি সার্ভার (instance)** রাখুন — একাধিক হলে ম্যাচ/ওয়ালেট গুলিয়ে যাবে।
6. হোস্টের দেওয়া `https://` লিংক খুলে: লবি আসছে? → `/admin`-এ ঢোকা যাচ্ছে? → দুটো ফোনে ২ অ্যাকাউন্ট খুলে ৳১০ জমা দিয়ে (অ্যাডমিন অ্যাপ্রুভ) একটা ম্যাচ খেলে দেখুন।
7. `/admin`-এর **Download backup** দিয়ে রোজ ব্যাকআপ নিজের পিসিতে নামান।

## রিস্টার্ট/ক্র্যাশে টাকা কেন হারায় না
- প্রতিটি লেনদেন ডিস্কে নিশ্চিত হয়ে তবেই কমিট হয় (SQLite WAL + synchronous=FULL)।
- চলমান ম্যাচ থাকা অবস্থায় সার্ভার বন্ধ হলে চালু হওয়ার সময় দুজনের এন্ট্রি ফি নিজে থেকে ফেরত যায়।
- দুজনই ১৫ মিনিট অফলাইন থাকলে ম্যাচ বাতিল, টাকা ফেরত।
- ৩০ মিনিট পরপর `backups/`-এ কপি হয় (শেষ ৪৮টি)।
